ApexCharts print test (#3352)

Open this file directly in a browser; it loads ../../dist/apexcharts.js, so run npm run build first if you have changed the source. Printing cannot be covered by the automated suites (a headless PDF is the only programmatic print, and it cannot be snapshot-compared), so this page is the manual check.

Widen this window first (the bug needs a chart wider than the print width, 700px by default), then press Cmd+P.

In the print preview: chart A should show all twelve months, Jan to Dec. Chart B opts out of the fix and should be cut off around Aug, which is what every chart did before. Chart C lays out at 900px, so on portrait paper it is scaled down to fit rather than cropped.

A. default (chart.print left alone)

Expect: complete chart, labels at normal size.

B. chart.print.enabled = false (the old behaviour)

Expect: cut off at the right edge of the paper.

C. chart.print.width = 900

Expect: complete, scaled down to fit the sheet.
